# Jurnal Rujukan

**Y. A. Hafiz & Endah Sudarmilah (2023)**  
*Implementasi Web Scraping pada Portal Berita Online*  
INISIASI, Volume 12 Nomor 1.

File PDF asli yang diunggah pengguna disertakan di folder project.

## Bagian yang dijadikan acuan

Jurnal menjelaskan:
- web scraping untuk pengumpulan data berita;
- Python dan BeautifulSoup;
- penentuan situs objek scraping;
- eksplorasi/navigasi HTML;
- identifikasi judul, URL, isi, tanggal, dan elemen artikel;
- pelaksanaan scraping;
- hasil yang dapat diekspor menjadi CSV. 

Jurnal juga menyebut bahwa hasil web scraping dapat dimanfaatkan untuk melihat tren/pola dan analisis sentimen terhadap berita/topik tertentu.

Project ini mengadaptasi alur pengambilan data tersebut untuk kebutuhan **web pencari sumber berita**, lalu menambahkan RapidOCR, TF-IDF, dan Cosine Similarity sebagai bagian dari rancangan sistem.
