## Batas

Jurnal rujukan digunakan sebagai dasar metode pengambilan data berita. RapidOCR, TF-IDF, dan Cosine Similarity merupakan rancangan project pencari sumber dan tidak diklaim sebagai metode yang diuji dalam jurnal rujukan.
