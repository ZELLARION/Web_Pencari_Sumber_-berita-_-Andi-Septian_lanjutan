# USER STORIES

## US-01 — Upload Citra

**Sebagai pengguna, saya ingin mengunggah citra berita agar sistem dapat membaca teks di dalamnya.**

Acceptance reference: FR-01.

## US-02 — Ekstraksi Teks

**Sebagai pengguna, saya ingin melihat teks hasil OCR agar saya dapat memastikan teks pada citra terbaca.**

Acceptance reference: FR-02, FR-11.

## US-03 — Penelusuran Sumber

**Sebagai pengguna, saya ingin sistem mencari artikel berdasarkan teks pada citra agar saya tidak perlu mencari secara manual.**

Acceptance reference: FR-05, FR-06.

## US-04 — Perbandingan Kandidat

**Sebagai pengguna, saya ingin melihat nilai kemiripan setiap kandidat agar saya dapat membandingkan sumber yang ditemukan.**

Acceptance reference: FR-08, FR-09.

## US-05 — Membuka Sumber

**Sebagai pengguna, saya ingin membuka URL artikel agar saya dapat memeriksa sumber secara langsung.**

Acceptance reference: FR-10.
